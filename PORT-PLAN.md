# Port plan: the whole prototype (except Super Admin) → this Next.js app

Written 2026-10-30. Sizes are lines of prototype source (`src/author-journey.jsx` is one 40k-line file; page components are counted from it, module pages from their folders). "Slice" = one working session like the ones used so far (build, test on the fake backend, README, report). This file is a plan, not a promise: re-count after each phase.

Rules that stay for every phase (already agreed): the prototype is the single source of truth for look and behaviour; only what the database holds is shown (no sample data); mock mode only for UI work; no live Supabase writes, no schema changes, no `.env.local` changes and no commits unless asked; every slice ends with `npx tsc --noEmit`, `npx eslint src`, a browser test against the fake Supabase, the README section and a report with the gaps.

Total: about **68 slices** after the ones already done (about 20 so far). The two big uncertainties are P6 (depends on D1) and P3 (largest single block).

### Recommended order
`P0 → P2 (Reviewer) → P3 (Chair core) → P1 → P4 → P5 → P7 → P6 → P8 → P9`.
Reason: P0 unlocks everything and is cheap; Reviewer and Chair core are what makes the product usable end to end on the database that exists today; P1 leftovers are small and can be slotted between; P6 waits for D1 so nothing is built twice.
