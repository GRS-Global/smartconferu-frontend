How it works

Built for conferences that run end-to-end

Every paper follows a structured journey. Smartconferu manages each step automatically — so chairs focus on quality, not coordination.

📄

Author submits the paper

Authors upload their manuscript, add co-authors, and complete the submission form. Versioned file management means revisions are tracked automatically.

  • Multi-author forms
  • File versioning
  • Submission confirmation
  • Deadline enforcement
👥

Chair assigns reviewers

Program chairs assign reviewers manually or via bidding. The system automatically detects conflicts of interest so you never have to cross-check manually.

  • Reviewer bidding
  • Auto conflict detection
  • Load balancing
  • Bulk assignment
🔍

Structured peer evaluation

Reviewers score papers on customizable criteria. Confidence levels, detailed comments, and confidential PC remarks are all captured in one structured form.

  • Customizable rubrics
  • Confidence scoring
  • PC-only remarks
  • Deadline reminders
✓

Chair makes final decisions

All reviews consolidated. Chairs see aggregated scores, reviewer consensus, and can accept, reject, or request revisions — with one-click notification to authors.

  • Score aggregation
  • Consensus view
  • Revision requests
  • Author notifications
📖

Proceedings generated

Camera-ready papers collected, formatted, and exported. Generate publication-ready proceedings in standard formats — ready for archiving or journal submission.

  • Camera-ready collection
  • Proceedings export
  • DOI assignment
  • Archive formats
